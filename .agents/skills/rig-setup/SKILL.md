# Настройка стенда

Цель — довести репо до состояния, когда остальные процедуры просто работают:
есть заполненный `rig.local.env`, есть каталог `rigs/<стенд>/`, и ты проверил,
что до ПК действительно достучаться можно.

Не выполняй шаги молча: это первый контакт человека с репо, объясняй,
что делаешь и зачем. Вопросы задавай по одному — не вываливай анкету целиком.

## 1. Проверь, не сделано ли уже

```bash
cat rig.local.env 2>/dev/null || echo "нет"
```

Если файл есть и заполнен — не переспрашивай всё заново. Покажи, что в нём,
и спроси, что поправить. Дальше иди сразу к шагу 5 (проверка связи).

## 2. Определи режим — это главный вопрос

Спроси, где запущен агент **прямо сейчас**:

- **`local`** — агент работает на том же Windows-ПК, где стоит видеокарта.
  Команды пойдут в локальный PowerShell. Ни SSH, ни правила файрвола, ни возня
  с VPN не понадобятся — это заметно более короткий путь.
- **`ssh`** — агент на другой машине (макбук, ноутбук) и ходит на ПК по сети.
  Понадобится OpenSSH на ПК, ключ и настроенный файрвол.

Не угадывай режим по операционной системе, на которой запущен ты: спроси.
От ответа зависит половина дальнейших процедур.

## 3. Собери параметры

Общие для обоих режимов:

| Ключ | Как получить |
|---|---|
| `RIG_NAME` | Предложи сам по видеокарте и объёму VRAM: `rtx4070-12gb`. Спроси подтверждение. |
| `RIG_MODE` | Из шага 2. |
| `RIG_ROOT` | Куда ставить хозяйство. Дефолт `C:\llm`, предложи его. |
| `RIG_API` | В local — `http://127.0.0.1:8080/v1`. В ssh — `http://<IP ПК>:8080/v1`. |

Дополнительно только для `RIG_MODE=ssh`:

| Ключ | Как получить |
|---|---|
| `RIG_HOST` | IP ПК в локальной сети. **Сразу предупреди**, что адрес должен быть статическим или закреплённым в DHCP роутера, иначе через неделю всё отвалится. |
| `RIG_SSH_USER` | Windows-юзер для SSH. Если у пользователя учётка с кириллическим именем — объясни, почему стоит завести отдельную ASCII-учётку (`docs/windows-notes.md`). |
| `RIG_SSH_KEY` | Путь к приватному ключу на стороне агента. Нет ключа — предложи сгенерировать и проведи по настройке OpenSSH из `docs/remote-access.md`. |
| `RIG_HOSTNAME` | Имя ПК в сети (`hostname`). Нужно редко, но пусть будет. |
| `RIG_WIFI_SSID` | SSID сети ПК. Нужен для починки профиля Public → Private. |

## 4. Запиши файл

Скопируй `rig.example.env` в `rig.local.env` и подставь значения. Комментарии
из шаблона сохрани — они объясняют, что есть что.

`rig.local.env` в `.gitignore` и коммититься не должен. Если пользователь просит
закоммитить — объясни, что там SSID и хостнейм, а по SSID в публичных базах
находится адрес дома; предложи вместо этого держать файл только локально.

Проверь, что файл читается скриптами:

```bash
python3 rig.py
```

Команда печатает разобранные параметры и то, как будет выглядеть вызов на ПК.

## 5. Проверь связь

**В local-режиме:**

```powershell
nvidia-smi
```

**В ssh-режиме** — той же командой, но через SSH:

```bash
ssh -i <RIG_SSH_KEY> -o BatchMode=yes <RIG_SSH_USER>@<RIG_HOST> 'nvidia-smi'
```

Если SSH таймаутит — не начинай чинить ключи и права. **Сначала спроси про VPN
на ПК:** AmneziaVPN, Outline и подобные забирают домашнюю подсеть в туннель,
и это самая частая причина. Второй кандидат — профиль сети сбросился в Public.
Оба разобраны в `docs/remote-access.md`.

Заодно вытащи характеристики железа — они понадобятся дальше:

```powershell
nvidia-smi --query-gpu=name,memory.total,driver_version --format=csv
Get-CimInstance Win32_Processor | Select-Object Name,NumberOfCores
Get-CimInstance Win32_ComputerSystem | Select-Object TotalPhysicalMemory
Get-PSDrive C | Select-Object Free
```

## 6. Заведи каталог стенда

Создай `rigs/<RIG_NAME>/` и в нём `current-setup.md` со всем, что узнал на шаге 5:
железо, режим работы, что уже установлено, а что ещё нет. Образец — `rigs/rtx5070ti-16gb/`,
но не копируй оттуда чужие модели и замеры: у нового стенда своя карта и свои цифры.

Добавь строку про новый стенд в таблицу в `rigs/README.md`.

## 7. Скажи, что дальше

Посмотри, что реально стоит на ПК (`<RIG_ROOT>` существует? есть ли `llama-server.exe`?),
и предложи следующий шаг:

- ничего нет → установка с нуля по `docs/install.md`;
- llama.cpp есть, моделей нет → подбор модели под VRAM по `docs/choosing-models.md`;
- всё стоит и отвечает → замеры по `docs/benchmarks.md`, чтобы было с чем сравнивать потом.

Закончи git-коммитом (`rigs/<RIG_NAME>/` и правку `rigs/README.md`;
`rig.local.env` в коммит не попадёт).
