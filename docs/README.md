# Документация

Переносимая часть проекта: то, что верно для любого игрового ПК с Windows и NVIDIA,
без привязки к конкретной машине. Всё, что привязано к железу — замеры, карточки моделей,
история конкретного стенда — лежит в [`rigs/`](../rigs/).

| Файл | Что внутри |
|---|---|
| [install.md](install.md) | **Начни отсюда** — установка с нуля: llama.cpp, модель, llama-swap, автозапуск |
| [choosing-models.md](choosing-models.md) | Как подобрать модель под свой объём VRAM: MoE vs dense, кванты, `-c`/`-ub`/`--n-cpu-moe` |
| [llama-swap.md](llama-swap.md) | Несколько моделей на одной видеокарте: конфиг, алиасы, выгрузка по простою, тонкости |
| [benchmarks.md](benchmarks.md) | Как мерить скорость честно и какие ошибки замеров типичны |
| [windows-notes.md](windows-notes.md) | Грабли Windows в обоих режимах: Fast Startup, планировщик, SID на русской системе, скачивание весов |
| [remote-access.md](remote-access.md) | Только для `RIG_MODE=ssh`: OpenSSH, VPN-ловушка, файрвол, job-объект |
| [server-scaleup-plan.md](server-scaleup-plan.md) | Исследование железа под отдельный сервер на 30–50 параллельных запросов |

## Если коротко, чего это всё стоило

Пять вещей, которые съели больше всего времени и которые стоит прочитать
до того, как наступишь сам:

1. **Fast Startup** — автозапуск молча не работает после обычного включения ПК
   ([windows-notes](windows-notes.md#fast-startup-ломает-автозапуск)).
2. **Спилловер VRAM** — сервер здоров, отвечает, но медленнее в десятки раз
   ([choosing-models](choosing-models.md#главный-симптом-ошибки--спилловер)).
3. **Версия CUDA у сборки llama.cpp** — не та сборка даёт кратную потерю скорости
   на ровном месте ([install](install.md#шаг-2-llamacpp)).
4. **VPN на ПК** забирает домашнюю подсеть и рвёт SSH — выглядит как умерший ПК
   ([remote-access](remote-access.md#vpn-ловушка--самая-частая-причина-всё-сломалось)).
5. **Русская Windows** — встроенные группы по имени не находятся, только по SID
   ([windows-notes](windows-notes.md#локализованная-русская-windows)).
