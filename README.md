# Локальная LLM на игровом ПК

Как превратить домашний игровой ПК с Windows и видеокартой NVIDIA в сервер с
OpenAI-совместимым API: несколько моделей на выбор, автозапуск, автоматическое
освобождение видеопамяти, когда садишься играть.

Репо рассчитано на то, что настраивать всё это ты будешь **через ИИ-агента**
(Claude Code, Codex, Cursor, Gemini CLI) — либо прямо на самом ПК, либо с ноутбука
по SSH. Скиллы для агента лежат в комплекте.

Это не универсальный туториал из интернета, а рабочие записи: что сработало,
что нет, и какие цифры получились на реальном железе.

## Быстрый старт

```bash
git clone <репозиторий> && cd <репозиторий>
cp rig.example.env rig.local.env
```

Дальше открой каталог агентом и скажи: **«настрой стенд»**.
Он спросит про твоё железо, заполнит `rig.local.env`, проверит связь с ПК
и подскажет следующий шаг. Руками — [docs/install.md](docs/install.md).

## Что получается на выходе

Один адрес, за которым несколько моделей — выбираются полем `model` в запросе:

```bash
curl http://<твой-пк>:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"default","messages":[{"role":"user","content":"привет"}]}'
```

Модель, которой давно не пользовались, сама уходит из видеопамяти — можно запускать
игру, не думая о сервере. Следующий запрос поднимет её обратно.

## Референсные цифры

RTX 5070 Ti 16 ГБ, кванты Q4, замеры через живой сервер
([методика](docs/benchmarks.md), [все цифры](rigs/rtx5070ti-16gb/benchmarks.md)):

| Модель | Контекст | prefill | decode |
|---|---|---|---|
| MoE 26B (~4B активных), целиком в VRAM | 32K | 6694 tok/s | 164 tok/s |
| dense 12B, целиком в VRAM | 64K | 4105 tok/s | 86 tok/s |
| MoE 35B (~3B активных), эксперты в RAM | 100K | 3126 tok/s | 70 tok/s |

Главный вывод: **MoE-модель крупнее вашей видеокарты работает быстрее,
чем dense-модель, ужатая до влезания.** Почему так — [choosing-models.md](docs/choosing-models.md).

## Пять вещей, которые съели больше всего времени

1. **Fast Startup.** Автозапуск молча не работает после обычного выключения ПК —
   потому что это не настоящий boot. ([подробно](docs/windows-notes.md#fast-startup-ломает-автозапуск))
2. **Спилловер VRAM.** Промахнулся с бюджетом памяти — сервер не падает, а начинает
   работать в десятки раз медленнее. ([подробно](docs/choosing-models.md#главный-симптом-ошибки--спилловер))
3. **Версия CUDA у сборки llama.cpp.** Не та сборка — кратная потеря скорости
   на ровном месте. ([подробно](docs/install.md#шаг-2-llamacpp))
4. **VPN на ПК** забирает домашнюю подсеть и рвёт SSH. Выглядит как умерший компьютер.
   ([подробно](docs/remote-access.md#vpn-ловушка--самая-частая-причина-всё-сломалось))
5. **Русская Windows.** Встроенные группы по имени не находятся — только по SID.
   ([подробно](docs/windows-notes.md#локализованная-русская-windows))

## Железо

Всё писалось на RTX 5070 Ti 16 ГБ, но привязки к ней нет: подбор модели под другой
объём видеопамяти — это [отдельный документ](docs/choosing-models.md) с ориентирами
для 8, 12, 16 и 24 ГБ. Windows 11 предполагается, потому что весь смысл затеи —
использовать игровой ПК, а не поднимать отдельный Linux-сервер.
